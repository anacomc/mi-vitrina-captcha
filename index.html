Consulta Rif online

===================

Aplicacion de escritorio para windows que te permite consultar comodamente el RIF

de tus Clientes y Proveedores, obtener su Nombre y porcentaje de retencion para mantener

tu base de datos actualizada al 100%

Puede ser usada interactivamente

Puede ser integrada es tus aplicaciones si eres desarrollador

Puede conectarse a SQL y actualizar tus datos de forma transparente

Puedes conectar con Excel y procesar una hoja de calculo que contenga los numeros de RIF

de Clientes y Proveedores y desde alli tu, si eres desarrollador, integrarlo a tus bases de datos

1. Consulta Individual y EditBox

Escribe el CAPTCHA, extrae los datos en 1 segundo y haz Ctrl+C para pegar en tu ERP.

2. Auditoría Masiva (Excel/SQL)

Ejecutalo contra una Hoja de calculo de Excel o contra una Tabla SQL para

corregir la informacion de Clientes y Proveedores
